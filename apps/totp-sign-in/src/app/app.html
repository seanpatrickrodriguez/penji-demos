Set up an authenticator, confirm it, save the recovery codes and sign in, then watch what the account checks for every code: the time step, the window either side of it, a code used twice and a lockout.

What the account checked

A sign-in page tells the person only whether the code worked. Behind it, each check compares the code with the codes for the current time step and the steps either side, refuses any step already used, and counts failures toward a lockout.
