DPRP recognition, evaluated from the records

A synthetic organization's participant records, evaluated against the 2024 CDC Diabetes Prevention Recognition Program Standards and, for Medicare participants, the Medicare Diabetes Prevention Program. Every result carries its evidence and its citation, and every rule is a definition you can read below.

A rebuild, on invented data, of how Penji, my private platform, handles compliance: standards as data, delivered to the platform's own forms and records, never shaping them. Change a record and every submission re-evaluates. Nothing leaves this page.

The standards, as data

Each standard is a definition: who it applies to, who it accepts, and the rules a record must meet. The compliance engine reads these and nothing else; adding the MDPP took a definition and no new code.

Architecture

The code follows the four layers of the OMG Meta Object Facility. Each layer is described by the one above it, and code at each layer reads the layer above instead of repeating it. One type system runs through every package.
